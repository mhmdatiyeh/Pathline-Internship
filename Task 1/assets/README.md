
# Chartwell Partners - Website Clone

## Project Overview
A recreation of the Chartwell Partners homepage using HTML, CSS, and JavaScript.

## Homepage Sections
1. Header / Navigation
2. Hero Section
3. Services Strip
4. Industry Expertise
5. Our Team (six profiles)
6. Why Companies Trust Us / Values / Statistics
7. Contact Footer / Office / Social Links

## Technologies
- HTML5
- CSS3
- JavaScript

## Running Locally
Open `../index.html` in a browser, or serve the `Task 1` directory using a local static server. No installation or build is required.

## Reference and Assets
Reference: https://chartwellpartners.com/ (reviewed November 7, 2026).

The photos, logos, and expertise icons were downloaded from the reference homepage. DM Serif Text and Fira Sans were downloaded from Google Fonts and are loaded through `fonts.css`. All page assets are stored locally.

The clone recreates the homepage sections and visual structure. Descriptive paragraphs are condensed adaptations. Profile, service-detail, and contact-page links lead to the original website; those pages are outside the homepage clone's scope.

## Header Interactions
- The search icon reveals an inline input, focuses it, and updates its accessible expanded state.
- Clicking the icon again, clicking outside, or pressing Escape closes the input.
- Search results are outside this UI implementation.
- Expertise and Services dropdowns open on hover or keyboard focus.

## Verification
Browser checks at widths of 320, 390, 768, 1024, and 1440 pixels covered horizontal overflow, inline search, closing interactions, keyboard dropdowns, local assets, and section anchors. No browser script errors were observed.
